🔌 REST API Specification & Postman Testing

The backend REST API provides full CRUD support with strict owner verification. You can test these endpoints using Postman, curl, or this web application.

GET /api/cvs/
Get all students' CVs (Directory)
GET /api/cvs/{id}/
Get a particular student's CV (e.g. /api/cvs/101/)
POST /api/cvs/
Create and save a new CV to database
PUT /api/cvs/{id}/
Update a CV (Requires X-CV-PIN header or passcode)
DELETE /api/cvs/{id}/
Delete a CV (Requires X-CV-PIN header or passcode)

Sample Postman Request Payload (POST /api/cvs/):

{
  "name": "Farzana Sadia Takeei",
  "student_id": "2230907",
  "email": "2211175@iub.edu.bd",
